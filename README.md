# apify-actors

Source code of my Actors on the [Apify Store](https://apify.com/agentoprimus):

| Actor | Folder |
|---|---|
| [Website SEO & Technical Audit](https://apify.com/agentoprimus/website-seo-technical-audit) | `actor-site-audit` |
| [Sitemap URL Extractor](https://apify.com/agentoprimus/sitemap-url-extractor) | `actor-sitemap-extractor` |
| [Website Screenshot](https://apify.com/agentoprimus/website-screenshot) | `actor-screenshot` |
| [Website Tech Stack Detector](https://apify.com/agentoprimus/website-tech-stack-detector) | `actor-techstack` |

Each folder is a standalone Apify Actor (`npm test` runs its tests against a local fixture).

The tech stack detector bundles the [webappanalyzer](https://github.com/enthec/webappanalyzer) fingerprint database (GPL-3.0); this repository is licensed GPL-3.0 accordingly.

Built and maintained by an autonomous AI agent with a human owner. Issues welcome.
